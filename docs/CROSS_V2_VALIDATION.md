## 问题与依据

阅读两个来源项目 README 后，对照实际调用链确认：本项目的 stage1/stage2 来自新版，stage3 则在一次中点细分后调用旧 student。旧版在原始 FLAME 上较稳定，不代表其同一组正则和位移限制适合约四倍面数的网格。

同一次 `20261025_150014_977582` 采集的历史诊断见 `diagnostics/20261025_150014_977582/`。未细分 student 的受控结果也出现额头凹陷，说明不能全部归因于细分；细分进一步增加中点独立偏离和子面折角。原补零锚点只保持初始位置，而旧几何约束允许边长到 0.25–4 倍，不能充分约束局部折皱。

## 修改范围

- 新版初始化、stage1/stage2 参数及源码未修改。
- 保留 student 三维位移、最近三角形对应、置信度、Huber、语义约束和深度筛选。
- 语义锚点改为实际子面重心坐标，初始位置不变。
- 增加中点位移相对两端平均的软约束，以及短边位移差加权。
- 总位移从 8 mm 限至 2 mm；新增每次更新 0.25 mm 上限。
- 复用新版 ShapeGuard：边长比 0.8–1.25、面积比 0.7–1.4、法线转角 20°、有符号邻面折角变化 10°，全部相对细分基准检查。
- 通过显式参数接入，不额外执行一套法线细化；不改变模型输入、指标计算或采集交互。

所有几何指标均是相对同一份未位移细分基准，且使用相同视角与光照制作图片。角度上限为几何保护，不是扫描评价指标。

### 深度贴合的代价

为避免只报告变平滑，在每种状态固定抽取 16,000 个可靠深度点（seed=42），分别计算它们到三份网格三角形表面的最近距离；不按结果删点，不使用每次优化不同的动态有效子集。

## 使用与局限

启动方式仍为 `python main.py` 或双击 `start.cmd`；新采集自动采用 v2。现有历史网格不自动替换，本次重算模型位于上述验证目录。

本次未重新验证硬件实时采集。几何保护不包含全局自交检测；初始 stage2 已存在的错误不会自动修复；过强的语义观测或错误深度仍可能在允许范围内引入形变。旧 student 的 0.1 mm 步长早停保留，因此受几何保护压小的更新也可能提前停止。当前配置优先限制明显局部畸变，真实精度与跨人的稳定性还需更多独立采集验证。
