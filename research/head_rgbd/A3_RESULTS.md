## 实际帧、运动和预算

原始为同一 Orbbec Gemini 215 的四个 5 帧短段，共 20 帧，1280×720。
四段分别为闭口 front/left/right 与张口 front；没有 up、没有张口侧面。
每段只有约 0.12–0.14s，段间有数秒缺口，不是长时连续转头视频。

先直接查看真实 RGB，在四个历史代表帧上新增本地人工 ROI 和 9 个命名点，
没有读取旧模型关键点或语义掩码。种子不确定性约 3px，不是独立真值。
经典 21px 灰度块匹配、±8px 搜索、NCC>=0.85 接通其余实际 RGB 帧，
20/20 通过匹配阶段；几何阶段 `closed_right_0` 三维稳定点不足四个而排除。

最终使用 19 个不同物理帧：闭口 front 5、left 5、right 4，张口 front 5。
全部原始帧索引、时间戳、SHA、匹配分数、深度有效性、拟合轨迹与排除原因在本地
`tracked_manifest.json` / `formal-v4/report.json`。不复制正面冒充 up 或侧面。

逐帧独立刚性姿态对齐共享上半脸，尺度固定 1。下半脸只融合真实参考同一短段内
与参考深度 <=1.5mm 的实际观测；不同状态/段的下颌不强行共享。
缺失参考深度须 >=2 实测一致支持才补入，未观测区域不凭模型补头。
相邻帧相关性很强，**多帧支持不等于多独立视角覆盖，也不是独立扫描覆盖率**。
没有完整下颌/表情系数优化或连续时间模型；颈部不进入人脸 ROI，未拟合颈部身份。

| 方法 | 实际输入/分辨率/预算 | 时间 | 内存口径 |

| 固定 v0.12.0 基线 | commit `3e409af...`，4 个融合观测，默认 FitOptions，只跑 stage2；历史原 1280×720 观测 | 109.79s | 历史 PyTorch 分配 341.72 / 保留 654.00 MiB |

## 同帧相同 ROI 的诊断

四个真实代表帧与先前基线/B 相同；CPU 三角形透视 Z-buffer，原始像素步长 4。
ROI 为这次新增人工裁剪，同一 ROI 用于所有方法，因此数值与旧报告不同。
表中误差是各模型命中射线上的**相机轴向训练残差**，不是独立欧氏表面误差。

| 帧 | 中位 mm 基线/B/A3 | P95 mm 基线/B/A3 | A3 射线重叠率 |
|---|---|---|---:|
| closed_front_1 | 1.686 / 1.144 / 0.307 | 8.459 / 5.721 / 1.127 | 95.86% |
| closed_left_0 | 1.650 / 0.493 / 0.610 | 5.880 / 2.096 / 2.783 | 86.08% |
| closed_right_3 | 1.836 / 0.480 / 0.926 | 6.371 / 1.958 / 4.365 | 92.24% |
| open_front_2 | 2.159 / 1.125 / 0.418 | 56.840 / 58.479 / 2.200 | 89.93% |

A3 孔洞较多，不能用删除/漏掉难点后较小的残差宣称更准确。
张口原 ROI 包含口腔深度和分离片；A3 不输出这些分离片，旧完整模型会投影其上，
因此上表张口尾部误差尤其不能直接比较优劣。另计算所有方法均命中的同一批射线：

| 帧 | 共同 ROI 比例 | 共同射线中位 mm 基线/B/A3 | P95 mm 基线/B/A3 |
|---|---:|---|---|
| closed_front_1 | 95.25% | 1.675 / 1.123 / 0.306 | 7.003 / 4.973 / 1.090 |
| closed_left_0 | 84.57% | 1.572 / 0.464 / 0.597 | 6.074 / 1.689 / 2.496 |
| closed_right_3 | 91.14% | 1.766 / 0.477 / 0.916 | 6.414 / 1.927 / 4.215 |
| open_front_2 | 87.57% | 1.903 / 1.015 / 0.408 | 7.825 / 4.017 / 2.076 |

正面共同射线还包括 front-only 控制的交集。未命中的 ROI 仍为缺失，不能计为准确。
B 在两侧的中位和尾部训练残差均优于 A3；A3 的直接深度表面更贴近参考训练帧，
但缺失区和参考状态处理不同，这不构成独立精度优势。

侧面加入后，正面对照共同射线：闭口中位 A3 full/front 为 0.306/0.297mm，
P95 为 1.090/1.021mm；张口中位 0.408/0.383mm，P95 2.076/1.987mm。
**正面训练残差略变差，不能宣称正面没有退化。**

未观察后脑/全侧面，无独立扫描，真实厚度及下颌角准确性未验证。

## 失败和降级

- 旧 A1：find_chin 候选不足越界，未将前脸当抬头绕过。
- smoke-v1：张口存在分离噪声/牙齿片，整体 Z 跨度约 319mm。改为最大连通
  观测脸导出，保留全部原始深度层，不做口内重建宣称。
- formal-v2/checks-v2：共享上半脸的细化跨越表情分界，误差最大约 0.83mm；
  检查以退出码1拦下。已分隔平滑邻域并添加回归测试，最终导出契约通过。
- 一次数值测试把浮点均值的 1.1e-16m 舍入当成失败；修改常量比较数值容差，
  几何门限和共享上半脸严格比较没有放宽。
- formal-v4：closed_right_0 有效三维稳定点不足，明确排除；其他实际右侧帧保留。
- 无 up、无张口侧面、无独立颈部/完整表达式模型；2.5D 表面无法恢复后脑/过悬区域。
